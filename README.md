# daily station

古いiPadなどの余剰タブレットを、壁掛け・デスク常設用の「スマート・デイリーステーション（情報ハブ端末）」として再活用するための軽量・単体完結型Webダッシュボードです。

外部サーバー、データベース、外部Webフォント、ビルド環境に一切依存せず、**1つのHTMLファイル（`index.html`）のみでGitHub Pagesやローカル環境で動作します**。

---

## 🌟 主な機能

### 1. 視認性最優先の日時・時計・生活動線連動リマインダー
* **大きな日本語カレンダー**: 年・和暦・月日・曜日を特大表示。
* **完全オフライン祝日計算**: 春分・秋分や振替休日を含め、内閣府の祝日規定をJavaScriptのみで自動計算（祝日は赤色ハイライト表示）。
* **チラつき抑止時計**: 秒表示を廃止し、1分ごとのジャスト同期更新により視界のチラつきを排除。
* **時間連動ごみ収集リマインダー**:
  * **朝〜日中（〜15:59）**: 「今日のごみ」を青色バッジで重点強調。
  * **夕方〜深夜（16:00〜）**: 前夜出しや翌朝の準備動線に合わせ、自動的に「明日のごみ」が青色強調表示にシフト。毎週および第N週の変則ルールに対応。

### 2. 天気予報・傘アラート（気象庁JMAモデル連携）
* **気象庁高精度モデル採用**: Open-Meteo経由で気象庁の局地数値予報モデル（JMA Seamless）を直接取得。CORS制限なく、日本国内の実感に即した高精度な予報を表示。
* **今日1日の天気推移モーダル**: 天気カードの「詳しく ↗」ボタンから、今日1日（00:00〜21:00の3時間おき固定8コマ）の天気・気温・降水確率・降水量を一覧表示。時間帯の配置が固定されているため直感的に把握でき、直近・次の時間帯が青枠で強調されます。Yahoo!天気（雨雲レーダー）への外部リンクも完備。
* **高視認性ウェザーアイコン**: ウェザーニュース社のカラー定義に準拠したセマンティックカラー（晴れ＝オレンジ、曇り＝グレー、雨＝青）のSVGアイコンを採用。
* **傘アラート**: 当日の最大降水確率が40%以上になると「☂️ 傘が必要」バッジが自動点灯。
* **シニアフレンドリー設計**: 最高/最低気温、降水確率、風速の数値を特大フォント（1.5rem）で表示。
* **GPS自動取得 & 手動都市選択**: GPS自動取得のほか、Wi-Fi版iPadでも即座に使える主要都市プリセットを内蔵。

### 3. 下段スワイプ切替モジュール（3画面）
下段のカードは左右スワイプまたは矢印ボタンで3つの画面を切り替えます（表示状態はブラウザに自動保存）。

1. **電車発車案内（カウントダウン）**
   * 最寄り駅の平日ダイヤ・土休日ダイヤを登録可能。祝日判定と連動して自動でダイヤが切り替わります。
   * **当日限定の手動ダイヤ切替（0時自動解除）**: 会社独自の休日やカレンダーにない振替日など、今日だけ「土休日ダイヤ」を適用したい場合はフッターの「ダイヤ切替」ボタンからワンタップで強制変更可能。深夜0時を過ぎると自動で通常判定に戻ります。
   * 「凡そモード（約○分後 / 1分更新）」と「詳細モード（分:秒 / 毎秒更新）」をワンタップで切替可能。
2. **週間カレンダー（明日からの7日間・拡大表示）**
   * 今日の情報重複を避け、明日から向こう1週間の日付・曜日・祝日名・日別天気予報・予想気温・ごみ収集予定を一覧表示。壁掛け遠景からの視認性に配慮し、文字サイズとアイコンを限界まで拡大。
3. **デイリーTodoチェッカー（5項目）**
   * 出発前の持ち物チェックや定常タスクをワンタップで消し込み（完了時刻を自動記録）。
   * 毎朝新しい状態で使えるよう、**深夜0時をまたぐと自動的に未完了へリセット**。タスク名は設定から自由に編集可能。

### 4. 24時間常時点灯・ディスプレイ保護・動的輝度制御
* **ピクセルシフト（焼き付き防止）**: 10分ごとに画面全体を微細（±3px）にランダム移動させ、液晶の素子固定・残像を防止。
* **時間帯別・疑似輝度制御 & タップブースト**:
  * `出勤準備モード`: 視認性最優先（輝度100%）。
  * `日中モード`: 通常時は55%前後に抑えて液晶保護・省電力化。画面タップで一定時間輝度を+20%（75%）に一時ブースト。
  * `深夜モード`: 就寝時の眩しさを防ぐ大幅減光（20%前後）＋強制ダークテーマ。画面タップで一定時間70%（眩しすぎない明るさ）に一時復帰。
* **ブースト時間のカスタム**: 日中・深夜のブースト継続時間をそれぞれ **30秒 / 1分 / 2分 / 3分 / 5分** から選択可能。作動中は画面左上に残り時間カウントダウンを表示（ボタン操作を邪魔しない安全配置）。

### 5. 完全ローカル完結・設定バックアップ
* 全ての設定（時刻表、地点、時間帯、輝度、ブースト時間、Todoタスク、ごみルール、当日ダイヤ指定）はブラウザの `localStorage` に保持されます。
* JSONファイルへのエクスポート、クリップボードコピー、テキスト貼り付けによるインポートに対応。PCで作成した設定をiPadへ即座に転送・復元できます。

## 📱 iPadでの推奨セットアップ手順

iPadを壁掛け・デスク常設ハブとして運用する場合、以下の設定を行うことで最も美しく動作します。

### 1. PWA（フルスクリーン）化
1. iPadのSafariでデプロイ先URLを開く。
2. 共有アイコンをタップし、「**ホーム画面に追加**」を選択。
3. ホーム画面に生成されたアイコンから起動すると、Safariのアドレスバーやタブが非表示になり全画面アプリとして動作します。

### 2. スリープの無効化
* iPadの「設定」アプリ ＞「画面表示と明るさ」＞「自動ロック」を「**なし**」に設定。

### 3. アクセスガイドの有効化（推奨）
* iPadの「設定」＞「アクセシビリティ」＞「アクセスガイド」をオンにする。
* 本アプリを開いた状態で電源ボタンをトリプルクリックしてアクセスガイドを開始すると、画面下部のホームバーや誤スワイプによるアプリ終了を完全に防止できます。

## ⚙️ 各種設定の記法

### ごみ収集ルール
設定モーダル内のテキストエリアに、1行につき1ルールを以下の形式で記述します。
* 火:燃やすごみ
* 金:燃やすごみ
* 水:有害・危険ごみ
* 第2木:ビン・缶・ペットボトル
* 第4木:ビン・缶・ペットボトル

### 電車時刻表
カンマ、スペース、または改行区切りで `HH:MM` 形式で記述します。
* 例: 06:10, 06:20, 06:30, 06:40, 06:49, 06:58, 07:07, 07:16...

## 🛠️ 技術スタック & 構成

* **フロントエンド**: Pure HTML5 / Modern CSS3 (Grid, Flexbox, Custom Properties) / Vanilla JavaScript (ES6+)
* **アイコン**: インラインSVG（ネットワークリクエスト・外部フォント依存ゼロ）

* **構成ファイル**:
  * `index.html`: アプリケーション本体（全コード統合）
